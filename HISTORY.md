# Project History - Flutter Postage Stamp Recognition App

## v1.0.0 (Current)
- **Feature**: Initial release of the Flutter cross-platform app.
- **Platform**: Support for Android, Web, and Windows.
- **Accessibility**: Comprehensive implementation of `Semantics`, keyboard navigation, and contrast themes.
- **Integration**: Connected to Flask/Roboflow backend for real-time stamp identification.
- **History**: Added session history tracking for detection results.

## Development Phase 2 (July 2026)
- **Migration**: Ported original detection logic to a structured Flutter frontend.
- **UI/UX**: Implemented Material 3 design system.
- **API**: Standardized `ApiService` for multi-platform byte/file handling.

## Development Phase 1 (Original Backend)
- **ML Engine**: Developed CNN models for stamp embedding and detection.
- **Database**: Implemented SQLite-based vector storage for cosine similarity matching.
- **Integration**: Integrated Roboflow for high-precision stamp localization.
